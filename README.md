# Netflix Movie Recommendation Engine

## Project Description

The **Netflix Movie Recommendation Engine** is a Python-based data science project designed to recommend movies to users based on movie characteristics and user preferences. Recommendation systems are widely used by OTT platforms such as Netflix and Amazon Prime to improve user experience and increase engagement by suggesting relevant content.

In this project, a Netflix movie dataset is analyzed using **Python, Pandas, NumPy, Matplotlib, and Seaborn**. The project begins with data collection and cleaning, followed by **Exploratory Data Analysis (EDA)** to understand movie release patterns, dataset characteristics, missing values, duplicates, and other important trends.

After preprocessing the data, **Natural Language Processing (NLP)** techniques are applied to movie titles. **TF-IDF (Term Frequency–Inverse Document Frequency)** is used to convert movie text into numerical features, and **Cosine Similarity** is used to measure the similarity between movies.

Based on these similarity scores, the recommendation engine generates a list of movies that are similar to the movie selected by the user.
